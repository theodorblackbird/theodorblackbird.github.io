Gated Linear Attention and Initial-State Tuning for Multi-Sample Prompting Text-To-Speech Synthesis

Théodor Lemerle1, Harrison Vanderbyl2, Vaibhav Srivastav3, Nicolas Obin1, Axel Roebel1

1IRCAM, STMS Lab · 2RWKV Foundation, EleutherAI, Recursal AI · 3Hugging Face

PMLR arXiv Code

Lina-Speech replaces self-attention with Gated Linear Attention. Because the model is recurrent, a voice can be cloned by tuning its initial state on several speech excerpts, instead of squeezing a single short prompt into the context window.

Initial-state tuning vs prompt continuation

Cloning from multiple speech excerpts captures finer details of a speaker's identity than a single prompt. All speakers are unseen. VoiceCraft's target text is cropped when needed because of its limited context window.
